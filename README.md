# Flask-WhooshPeewee
Flask + Whoosh + peewee

Flask-WhooshPeewee is a Flask extension that mixes the searching and indexing functionality of Whoosh with the Schema
of peewee for use in Flask applications.

# Requirements

* python >= 3.10
* peewee >= 3.17.9
* whoosh >= x.x.x
* Flask >= 3.0.0

# Installation

```
pip install Flask-WhooshPeewee
```
